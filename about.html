Multilayer network visualization — every view, in one browser tab

MiRA (Multilayer Interactive Rendering Application) is a free, browser-based, installation-free tool for interactive visualization of multilayer networks in ecology and biology — multiplex, temporal, spatial, and bipartite — and linked to R in both directions. Other tools each cover a piece; MiRA brings the whole picture together.

One tool, seven views

Seven linked visualization modes

Each mode provides a different perspective about the same network. MiRA is the only tool that offers all of them — and switches between them in a single click, keeping your selection, color, and filtering choices intact across every view.

Network

All layers in one 3D space — rotate, pan, and drag to explore structure.

Map

Layers pinned to their real geographic coordinates on an interactive world map.

Layer

Each layer as a force-directed bubble, with side-by-side comparison panels.

Grid

Small multiples — one panel per layer, side by side for direct comparison.

Meta-Network

Aggregate cross-layer structure into a single monolayer graph.

Dashboard

Charts, presence matrices, similarity heatmaps, and degree distributions.

Data

Inspect, filter, and subset the underlying node, link, and layer tables.

Interactive + R

From R to MiRA and back

Exploring with the mouse and scripting in R are not a choice. With the ggmira R package, a plot written in R opens in MiRA, fully interactive. Change it there, then click MiRA's R button: it gives back the R code for exactly what you see, ready for your script.

1. Write it in R

mira(net) plus components for the layout, nodes, links, layers, filters and view, in a ggplot2-like syntax.

2. Explore it in MiRA

The plot opens in the browser or in RStudio's Viewer pane, with all seven modes: rotate, filter, recolor, switch views.

3. Copy it back as R code

The R button turns the current view, with what you changed by mouse, into ggmira code. mira_save() writes the figure from a script.

Full support Partial / limited Not available

Several tools for multilayer visualization exist, but none combines the full set of features ecological research needs. muxViz is an established analysis tool, but it runs in R, offers no interactive browser interface, and does not support bipartite networks. BiMultiNetPlot fills the bipartite gap yet produces only static figures with no built-in analysis. Arena3Dweb offers polished interactive 3D, but was designed for biomedical networks — without bipartite or geographic layouts, or multiple linked views. General-purpose tools such as Gephi and Cytoscape are not multilayer-native. Each covers only a fragment of what ecological multilayer visualization requires, which is the gap MiRA fills. MiRA is also the only one in which the interactive view and R code feed each other: the ggmira R package opens a network in MiRA from R, and MiRA's R button turns the view back into R code. See each tool's docs for current features.

FAQ

Frequently asked questions

What is a multilayer network?

A multilayer network is composed of a set of layers (each is a network), which represent different states of the entire system, such as different kinds of interactions, spatial locations or temporal time points. The layers are a single linked structure via interlayer links, rather than collapsed into a single graph. MiRA visualizes all of these — see the visualization modes in the manual.

Is MiRA free?

Yes. MiRA is free and open source under the CC BY-NC-SA 4.0 license, runs in any modern web browser, and requires no account or sign-up. See License & Attribution in the manual.

Do I need to know how to code to use MiRA?

No. MiRA is entirely point-and-click in the browser. Coding is optional: if you work in R, the ggmira package opens your networks in MiRA from R and turns MiRA's view back into R code (see the next question).

Can I use MiRA from R?

Yes, in both directions. With the ggmira R package, mira(net) opens a multilayer network from the emln package in MiRA, and components added with + set the layout, colors, filters and view, in a ggplot2-like syntax. In the other direction, MiRA's R button (Copy as R code) gives the ggmira code for the current view, including changes made with the mouse. mira_save() writes the figure as a PNG, JPG or PDF from a script, so figures stay reproducible.

Can MiRA visualize bipartite networks such as plant–pollinator or host–parasite webs?

Yes. MiRA has a dedicated bipartite layout that draws the two node sets — for example pollinators and plants — in separate rows. Mark a layer as bipartite in your data and MiRA lays it out automatically; see bipartite layers in the manual, or the plant–pollinator walkthrough.

What data formats does MiRA read?

MiRA reads JSON or CSV (an extended edge list plus optional layer, node, and state-node attribute files), or a network sent directly from R by the ggmira package. See the data format guide or the manual's import section.

How is MiRA different from other software?

Each of the existing tools covers part of what multilayer visualization needs. For example, muxViz and pymnet are focused on analysis, Arena3Dweb for biomedical 3D scenes, and Gephi and Cytoscape for general single-layer graphs. MiRA is the only tool that brings together interactive visualization in the browser, a two-way link with R (the ggmira package), bipartite and geographic support, and seven linked visualization modes.

How do I cite MiRA?

Cite the preprint: Nehoray, Bloch & Pilosof (2026), Interactively visualizing biological multilayer networks using MiRA, arXiv:2605.09597. To cite the software itself, use the Zenodo DOI 10.5281/zenodo.22096810.
