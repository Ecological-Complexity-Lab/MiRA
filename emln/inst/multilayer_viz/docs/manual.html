Multilayer Network Visualizer

Interactive manual — all features, modes, and controls

🌎 Visualization Modes

The application supports four visualization modes. The active mode is controlled by the buttons in the bottom-left toolbar. The left-side control panel changes completely depending on which mode is active.

🕸️ Network Mode Default

All layers are rendered simultaneously within a continuous 3D coordinate space.

  • Rotate the 3D Space — drag anywhere on the background.
  • Pan — hold Shift + drag.
  • Drag Layers — hold Cmd (Mac) / Ctrl (Win) + drag a layer outline to physically reposition it.

The left panel shows four collapsible sections: Data, Layers, Nodes, and Links.

🗺️ Map Mode

Bridges geographic analysis with network structure. Only available when the dataset includes latitude and longitude on its layers.

  • Layer Markers — layers appear as interactive blue circle markers on a Leaflet world map.
  • Pop-Out Layers — click a marker to pop that layer into floating 3D space. Multiple layers can be popped simultaneously.
  • Dynamic Close Buttons — a red ✕ sticks to each popped layer; click it to return the layer to the map.
  • Map Opacity Slider — fade out the satellite imagery. Uncheck "Show Map" to remove it entirely while keeping geographic spacing.
  • Map Navigation — pan and zoom the Leaflet map freely. Shift + drag pans the map and carries any popped-out 3D layers with it.

The left panel is the same as Network Mode, with a Map section added at the top.

📊 Dashboard Mode

Replaces the network canvas with quantitative analytics panels. All sections are collapsible — click a section header to expand or collapse it.

Left panel controls (Dashboard-specific):

  • Sort layers by — order layers in all charts by: Participation, Nodes, Intra-links, Inter-links, or Density.
  • Highlight metric — which metric accent-colors the tallest bar in each chart.
  • Show bipartite panels — toggle (bipartite networks only): hide/show Set A / Set B split panels.

KPI Cards

Five headline numbers: total unique nodes, total layers, total intralayer links, total interlayer links, and mean edge density across all layers.

Per-Layer Bar Charts

Side-by-side bars for each layer showing node count, intralayer links, interlayer links, and edge density. The highest-value bar in each chart is accent-colored. For bipartite networks the node-count chart becomes a stacked bar split by Set A and Set B. Clicking a layer name highlights it in the background network.

Node × Layer Presence Matrix

A heatmap showing which nodes appear in which layers. A toggle switches orientation:

  • Layer rows × Node cols (default) — exploits screen width when there are more nodes than layers.
  • Node rows × Layer cols — traditional orientation.

Sort buttons reorder rows/columns alphabetically or by participation count. Bipartite networks color rows by set membership.

Layer Similarity (Jaccard)

Square heatmaps where rows and columns are both layers. Each cell shows the Jaccard similarity (0 = white → 1 = full accent color).

  • Node identity — overlap in which physical nodes appear. Bipartite networks show separate Set A and Set B matrices (three matrices total).
  • Edge identity — overlap in which edges (by node-pair key) appear across layers, shown in amber.

The diagonal equals 1 by computation. Empty layers produce a gray cell (NaN).

Degree Distributions

Histograms of node degree for the full network and per layer. Bipartite networks show separate histograms for Set A and Set B.

Node Participation

Bar chart showing how many layers each node appears in, sorted by count. Bipartite networks show Set A and Set B separately.

Set Size Ratio bipartite only

Bar chart showing the ratio of Set A to Set B nodes within each layer — a quick view of balance across layers.

🔵 Layer View (Meta-Graph Mode)

A novel mode that abstracts away individual nodes and renders layers themselves as the primary objects. Each layer becomes an interactive bubble in a force-directed meta-graph.

  • Inside each bubble, a micro-graph preview shows the internal topology (node positions and edges at reduced opacity).
  • Blue solid lines between bubbles — interlayer links. Thickness = number of such links.
  • Gray lines — shared physical nodes. Thickness = fraction of shared nodes.
  • Bubbles are arranged by Fruchterman-Reingold force layout. Isolated layers are kept close by stronger gravity.

Interactions

  • Drag a bubble to pin it. Click Reset to unpin all and re-run layout.
  • Click a bubble to select it — others fade. A Layer Stats panel slides in showing identity, size, connectivity, and cross-layer connectivity.
  • Cmd+click (Mac) / Ctrl+click (Win) a second bubble to open a Layer Comparison panel:
    • Size: nodes and edges for A vs. B.
    • Overlap: shared nodes (count and %), Jaccard index, shared edges.
    • Divergence: density ratio, size ratio, overlaid degree-distribution histogram.
    • Cross-layer links: interlayer link count between the two layers specifically.
  • Click empty space to deselect and clear the stats panel.
  • Scroll to zoom (centered on cursor); drag background to pan.

Sidebar Controls

Layers section:

  • Size by — bubble radius driven by: Number of nodes, Number of edges, Edge density, or Uniform.
  • Color by — Layer (categorical palette), Node count (YlOrRd scale), Edge density (YlOrRd scale), or Uniform.
  • Size multiplier — global scale slider (0.5× – 2.0×).
  • Show layer name labels — toggle text labels below bubbles.
  • Label font size — slider.
  • Bubble spacing — equilibrium distance in the force layout.

Edges section:

  • Show edges — toggle all meta-edges.
  • Edge metric — Interlayer links, Shared nodes, or Both.
  • Min edge weight — hide edges below this threshold.
  • Show edge weight labels — toggle numeric labels on edges.

🎛️ Control Panels (Network / Map Mode)

The side menu has four collapsible accordions, visible in Network and Map modes.

1. Data

Always visible regardless of mode.

  • Load Example Data — built-in datasets: Directed, Large Scale, Simple Bipartite, Complex Bipartite (Bartomeus), Pond Ecosystem, Synthetic Bipartite (10 layers), Synthetic Unipartite (10 layers).
  • Load User Data (JSON) — upload a local JSON file. See the JSON structure below.
  • Load User Data (CSV) — load directly from emln CSV output. A modal dialog accepts:
    • Extended Edge List (required) — columns layer_from, node_from, layer_to, node_to, weight (optional). Both intralayer and interlayer links go here.
    • Layer Attributes (optional) — layer_id, layer_name, latitude, longitude. Auto-derived if omitted.
    • Node Attributes (optional) — node_name, group (or node_type/type). Auto-derived if omitted.
    • Directed / Bipartite checkboxes set network type before loading.
    • Comma, tab, and semicolon delimiters are all auto-detected.

2. Layers Network / Map

  • Layer Names — toggle floating title tags above each plane.
  • Stacking Mode — Horizontal (layers recede into Z-axis, default) or Vertical (layers drop along Y-axis).
  • Layer Spacing — simulated physical distance between planes.
  • Layout Algorithm — Fruchterman-Reingold, Kamada-Kawai, Bipartite (two-row with optional nested sorting), Circle, Grid, or Random.

3. Nodes Network / Map

  • Node Labels — show node names on hover or permanently.
  • Transform Nodes — skew nodes to match the isometric perspective of their layer plane. Disable for large networks to improve performance.
  • Color By — Layer, Group, or Uniform. Bipartite networks show independent color pickers for Set A and Set B.
  • Size By — uniform Base Size slider, or scale by Node Degree.

4. Links Network / Map

  • Show Interlayer Links — toggle cross-layer edges.
  • Color By — by type (Inter vs. Intra) or by originating layer color.

📊 Dynamic Legend

A legend panel appears in the bottom-right corner whenever color or size mappings are active.

  • Draggable — drag the title bar to reposition anywhere on screen.
  • Collapsible — click − to collapse to a tab; click the tab or + to expand again.
  • Closeable — click ✕ to dismiss. Reappears on new data load or setting change.
  • Interactive toggle (Layer View) — when coloring by Node count or Edge density, a button switches between a continuous gradient bar and a categorical list.

📸 Bottom-Left Toolbar

  • ? (Manual) — opens this manual in a new tab.
  • Snapshot (camera icon) — high-resolution export. Choose PNG, JPG, or PDF; optionally include the backdrop grid.
  • + / − / Reset — zoom in/out and reset viewport. In Layer View, Reset also unpins all bubbles and re-runs the force layout.
  • Dashboard (📊) — toggle Dashboard Mode.
  • Layer View (three circles) — toggle Layer View / Meta-Graph Mode.
  • Map Mode (map icon) — toggle geographic Map Mode (only shown when the dataset has coordinates).
  • Interaction Hints — quick-reference cheatsheet for mouse bindings.

🖱️ Advanced Interactions (Network Mode)

  • Node / Link Hover — highlights nearest connections and dims the rest. A tooltip shows exact node data.
  • Selection Focus — click a node to lock its web of connections. Click the background to clear the selection.
